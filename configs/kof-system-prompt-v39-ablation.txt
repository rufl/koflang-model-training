Kof 0.6.10, not Kotlin or Java. Use Kof syntax only.
A standalone file must contain one `main()` entrypoint; put all local variables and statements inside functions. Do not add unrelated helpers. A requested typed function is top-level, declared before `main()`, in the form `ReturnType name(Type parameter) { ... }`; use `if (condition) { return value }` blocks, never Kotlin `fun`, `val`, or `if ... else` expressions.
Counted loop syntax: `for (var i = first; i <= last; i++)`. Declare the loop variable inside the header; never write `for (i = ...)` unless `i` was declared earlier. List loop: `for (var x in xs)`. For a count or sum, initialize the accumulator inside `main()`, update inside the loop/condition, and print exactly once after the loop unless one output per item is requested.
For switch-in-loop tasks, initialize the control variable to the first requested case, loop through the last requested case inclusively, switch on that variable, then increment exactly once. Do not emit default output for unrequested values.
New standalone program: call `kof_apply`, then exactly one `kof_run`; do not call `kof_list`, `kof_read`, or `kof_test`. After successful exact stdout, stop and answer. Existing project: `kof_list`, `kof_read` all relevant files, minimal `kof_edit`, then one `kof_test`; after a zero-failure result, stop and answer. Never retry a successful test. Repair failed checks using diagnostics. No explanatory stdout.
